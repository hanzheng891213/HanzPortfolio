 HanzPortfolio — 接入后端及数据库

 Context

 当前项目是纯前端 SPA，所有数据（博客文章、用户认证、点赞/浏览记录）完全依赖
 localStorage，没有真正的后端。这导致：
 - 登录状态仅存在于当前浏览器，换个设备就丢失
 - 博客文章无法跨设备共享
 - 点赞/浏览数据各自独立
 - 没有真正的安全性（token 是 base64 编码的时间戳）

 用户正在部署到 Cloudflare Pages，需要接入后端 API 和数据库。

 数据库设计

 users

 id INTEGER PRIMARY KEY AUTOINCREMENT
 email TEXT NOT NULL UNIQUE
 password_hash TEXT NOT NULL        -- PBKDF2: salt:hash
 role TEXT NOT NULL DEFAULT 'visitor' CHECK(role IN ('admin','visitor'))
 created_at TEXT NOT NULL DEFAULT (datetime('now'))

 blog_posts

 id INTEGER PRIMARY KEY AUTOINCREMENT
 title TEXT NOT NULL
 summary TEXT NOT NULL DEFAULT ''
 content TEXT NOT NULL DEFAULT ''
 tags TEXT NOT NULL DEFAULT '[]'   -- JSON 数组
 cover TEXT NOT NULL DEFAULT ''
 author TEXT NOT NULL DEFAULT ''
 created_at TEXT NOT NULL DEFAULT (datetime('now'))
 updated_at TEXT NOT NULL DEFAULT (datetime('now'))
 like_count INTEGER NOT NULL DEFAULT 0
 view_count INTEGER NOT NULL DEFAULT 0

 blog_likes

 id INTEGER PRIMARY KEY AUTOINCREMENT
 post_id INTEGER NOT NULL REFERENCES blog_posts(id) ON DELETE CASCADE
 user_email TEXT NOT NULL
 created_at TEXT NOT NULL DEFAULT (datetime('now'))
 UNIQUE(post_id, user_email)

 blog_views

 id INTEGER PRIMARY KEY AUTOINCREMENT
 post_id INTEGER NOT NULL REFERENCES blog_posts(id) ON DELETE CASCADE
 user_email TEXT NOT NULL
 created_at TEXT NOT NULL DEFAULT (datetime('now'))
 UNIQUE(post_id, user_email)

 API 设计

 所有接口前缀 /api，JSON 请求/响应。

 Auth

 ┌──────┬─────────────────┬────────┬─────────────────────────────┐
 │ 方法 │      路径       │  认证  │            说明             │
 ├──────┼─────────────────┼────────┼─────────────────────────────┤
 │ POST │ /api/auth/login │ 无     │ 登录，返回 JWT token + user │
 ├──────┼─────────────────┼────────┼─────────────────────────────┤
 │ GET  │ /api/auth/me    │ Bearer │ 获取当前用户信息            │
 └──────┴─────────────────┴────────┴─────────────────────────────┘

 Posts

 ┌────────┬─────────────────────┬──────────┬──────────────────────────┐
 │  方法  │        路径         │   认证   │           说明           │
 ├────────┼─────────────────────┼──────────┼──────────────────────────┤
 │ GET    │ /api/posts          │ 无       │ 文章列表（按日期降序）   │
 ├────────┼─────────────────────┼──────────┼──────────────────────────┤
 │ GET    │ /api/posts/:id      │ 无       │ 文章详情                 │
 ├────────┼─────────────────────┼──────────┼──────────────────────────┤
 │ POST   │ /api/posts          │ Admin    │ 创建文章                 │
 ├────────┼─────────────────────┼──────────┼──────────────────────────┤

 本地开发

 # 终端 1 — 前端 (Vite HMR, port 3000)
 npm run dev

 # 终端 2 — API Worker (wrangler dev, port 8787)
 npm run dev:api

 # 初始化数据库
 npx wrangler d1 create hanz-portfolio-db
 npx wrangler d1 execute hanz-portfolio-db --file=db/schema.sql
 npx wrangler d1 execute hanz-portfolio-db --file=db/seed.sql

 Vite proxy: /api → http://localhost:8787/api

 部署步骤

 1. 在 Cloudflare Dashboard 创建 D1 数据库 hanz-portfolio-db
 2. 本地执行建表：npx wrangler d1 execute hanz-portfolio-db --file=db/schema.sql --remote
 3. 本地执行种子数据：npx wrangler d1 execute hanz-portfolio-db --file=db/seed.sql --remote
 4. 在 Cloudflare Dashboard → Pages → 项目 → Settings → Functions → D1 bindings 添加绑定：DB →
 hanz-portfolio-db
 5. 在 Pages → Settings → Environment variables 添加 JWT_SECRET（随机字符串）
 6. Push 到 main 分支即可自动部署

 验证方式
